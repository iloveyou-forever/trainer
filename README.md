# Перекладина — сервер

Трекер калистеники с настоящими аккаунтами. Данные хранятся на вашем сервере, ссылка не зависит от Claude.

## Что внутри
- Регистрация, вход, выход, сброс пароля по почте, роли «Админ / Пользователь».
- Приложение отдаётся **только после входа**: без аккаунта нельзя получить ни страницу, ни данные, ни ИИ. Обойти это в браузере нельзя, проверки идут на сервере.
- Прогресс тренировок и настройки синхронизируются между устройствами.
- ИИ-анализ по фото через ваш ключ Anthropic. Фото не сохраняются: они уходят в API и стираются из памяти. Лимит анализов в сутки на пользователя.
- Панель администратора (кнопка 👤): список пользователей, смена роли, блокировка, удаление.
- Безопасность: пароли хешируются (scrypt), сессии в защищённых cookie (HttpOnly, SameSite, Secure на HTTPS), лимиты попыток входа, защита от CSRF, заглушка по времени против подбора email.

## Запуск на своём компьютере
Нужен Node.js 22.5 или новее.

    npm install
    ADMIN_CODE=мой-секретный-код node server.js

Откройте http://localhost:3000. Первый администратор: «Регистрация» → «У меня есть код администратора» → введите ADMIN_CODE.

## Выкладка в интернет (нужен хостинг с постоянным диском)
База лежит в файле `DATA_DIR/app.db`. Хостинг без постоянного диска стирает её при перезапуске, поэтому бесплатные тарифы «без диска» не подходят.

**Вариант 1: Railway.** New Project → Deploy from GitHub (загрузите эту папку в репозиторий) → Variables: добавьте переменные из `.env.example` и `DATA_DIR=/data` → Volumes: подключите том к `/data` → Settings → Generate Domain.

**Вариант 2: Fly.io.** `fly launch`, затем `fly volumes create data --size 1`, в `fly.toml` добавьте `[mounts] source="data" destination="/data"`, секреты: `fly secrets set ADMIN_CODE=... ANTHROPIC_API_KEY=... BASE_URL=...`, затем `fly deploy`.

**Вариант 3: VPS (от 4 € в месяц).** Установите Docker, затем:

    docker build -t perekladina .
    docker run -d --restart=always -p 3000:3000 -v perekladina-data:/data --env-file .env perekladina

и поставьте перед контейнером Caddy или Nginx для HTTPS (cookie с флагом Secure работают только по HTTPS).

## Свой домен
Купите домен, направьте A-запись на сервер (на Railway/Fly: добавьте домен в настройках и создайте CNAME).

## Резервные копии
Копируйте файл `app.db` (с `app.db-wal`, если он есть) раз в день. Это вся ваша база.

## Важно
- Храните `ADMIN_CODE` и `ANTHROPIC_API_KEY` только в переменных окружения, не в репозитории.
- ИИ-анализ расходует деньги с вашего ключа: настройте лимит расходов в консоли Anthropic и держите `AI_DAILY_LIMIT` небольшим.
- Вы храните имена и email людей: сообщите им об этом (в форме регистрации есть согласие) и удаляйте по запросу (кнопка «Удалить мой аккаунт» или панель администратора).
- Сервис с фото тела требует осторожности: фото нигде не сохраняются, вход только для 18+, ИИ отказывается анализировать откровенные снимки и людей младше 18. Не отключайте эти ограничения.

## Pro-подписка и питание
- Кнопка 🥗 открывает «Питание». Бесплатным пользователям показывается описание Pro и ссылка `PRO_BUY_URL`, а у Pro есть форма и персональный план: калории и БЖУ считаются на сервере по формуле, ИИ только составляет блюда и список покупок.
- Pro включает администратор: панель 👤 → у нужного пользователя кнопка ⭐ → число дней (0 — отключить). Админ всегда имеет Pro.
- Лимиты в сутки (переменные Railway): `AI_DAILY_LIMIT` (бесплатные, по умолчанию 3), `AI_PRO_LIMIT` (Pro, 30), `NUTRITION_DAILY_LIMIT` (планов питания, 5).
- `PRO_BUY_URL` — https-ссылка на вашу страницу оплаты (Boosty, Telegram-бот и т. п.). Автоматического приёма платежей в сервере пока нет: оплату принимает выбранный вами сервис, а Pro вы выдаёте вручную. Подключение платёжного сервиса с автоматической выдачей — отдельный шаг.
- Безопасность питания: только 18+, возраст 18–80, рост 130–220, вес 40–250. При ИМТ ниже 17 (или ниже 18,5 при цели «похудение») план не составляется. Дефицит не больше 15%, минимум 1500 ккал для мужчин и 1200 для женщин. В каждом плане есть отказ от ответственности и совет обратиться к врачу.
